## 🌦️ Weather App

A simple full-stack weather application built with Angular (frontend) and .NET (backend).
It fetches real-time weather data from the OpenWeatherMap API
 and displays it in a clean, user-friendly interface.

## 🚀 Features

🔍 Search for a city and view current weather conditions

📅 5-day / 3-hour forecast display

🌡️ Temperature, humidity, and condition icons

🖼️ Weather-themed images with fallback support

⚡ API integration with robust error handling

## 🛠️ Tech Stack

### Frontend:

Angular

TypeScript

HTML / SCSS

### Backend:

.NET 6+ Web API

C#

HttpClient for API requests

### Other:

OpenWeatherMap API

xUnit for backend unit tests
